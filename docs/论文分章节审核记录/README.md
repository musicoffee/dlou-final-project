## 每次审核步骤

1. 我先对照实际代码、数据库和测试材料检查本章内容。
2. 再检查标题、字体、字号、行距、缩进和分页。
3. 检查图片、表格、图题、表题和正文引用。
4. 检查本章页眉和页码是否正确。
5. 保存检查前、修改过程和修改后的真实截图。
6. 在对应的 `审核记录.md` 中写下问题和修改结果。
7. 每次只提交这次检查涉及的文件，提交信息继续使用 `type_lfp: subject` 格式。

截图建议命名为：

```text
01_审核前.png
02_修改过程.png
03_审核后.png
```

没有实际检查和截图时，我不会用空白图片或别的图片代替。
