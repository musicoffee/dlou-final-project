# 红色文化学习打卡系统运行说明

## 文件说明

| 文件或文件夹 | 作用 |
| --- | --- |
| `database.py` | 创建并连接 SQLite 数据库 |
| `service.py` | 处理注册、登录、查询、打卡和管理业务 |
| `server.py` | 启动 HTTP 服务端 |
| `setup_admin.py` | 首次设置唯一管理员 |
| `api_client.py` | 封装客户端 HTTP 请求 |
| `client.py` | 启动 Tkinter 桌面客户端 |
| `tests/` | 自动化测试代码 |
| `requirements.txt` | 依赖说明，本项目仅使用 Python 标准库 |

## PyCharm 运行方式

1. 用 PyCharm 打开本文件所在的代码文件夹。
2. 第一次运行时打开 `setup_admin.py`，点击绿色三角形设置管理员。
3. 打开 `server.py`，点击绿色三角形并保持运行。
4. 打开 `client.py`，点击绿色三角形打开系统界面。
5. 同机使用时，服务端地址保持 `http://127.0.0.1:8765`。

管理员已经存在时，不需要重复设置。数据库保存在本文件夹下的 `data/learning.db`，该文件只在本机使用，不上传 GitHub。

## 终端运行方式

进入本代码文件夹后依次运行：

```bash
python3 setup_admin.py
python3 server.py
```

保持服务端运行，再打开一个终端窗口并进入相同文件夹：

```bash
python3 client.py
```

## 自动化测试

```bash
python3 -m unittest discover -s tests -v
```

## 局域网运行

服务端电脑使用以下方式启动：

```bash
LEARNING_HOST=0.0.0.0 python3 server.py
```

另一台电脑需要保存本代码文件夹并运行 `client.py`，然后将登录页面的服务端地址改为：

```text
http://服务端电脑的局域网IP:8765
```
