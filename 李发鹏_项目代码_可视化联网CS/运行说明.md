# 红色文化学习打卡系统运行说明

## 文件说明

| 文件或文件夹 | 作用 |
| --- | --- |
| `database.py` | 创建并连接 SQLite 数据库 |
| `service.py` | 处理注册、登录、查询、打卡和管理业务 |
| `server.py` | 启动 HTTP 服务端 |
| `api_client.py` | 封装客户端 HTTP 请求 |
| `client.py` | 启动 Tkinter 桌面客户端 |
| `tests/` | 自动化测试代码 |
| `requirements.txt` | 依赖说明，本项目仅使用 Python 标准库 |

## PyCharm 运行方式

1. 用 PyCharm 打开本文件所在的代码文件夹。
2. 打开 `server.py`，点击绿色三角形并保持运行。
3. 打开 `client.py`，点击绿色三角形打开系统界面。
4. 同机使用时，服务端地址保持 `http://127.0.0.1:8765`。
5. 登录前可以点击“测试服务端连接”，看到“连接成功”后再登录。

管理员不需要注册，固定账号为 `lfp`，密码为 `123456`。普通用户通过客户端注册。数据库保存在本文件夹下的 `data/learning.db`，只包含用户、景点、用户景点打卡记录和公告四张表；该数据库文件只在本机使用，不上传 GitHub。

## 终端运行方式

进入本代码文件夹后依次运行：

```bash
python3 server.py
```

保持服务端运行，再打开一个终端窗口并进入相同文件夹：

```bash
python3 client.py
```

## 自动化测试

```bash
python3 -m unittest discover -s tests -v
```

## 局域网运行

`server.py` 默认监听 `0.0.0.0`，直接点击绿色三角形即可允许同一局域网的客户端连接。

在服务端 Mac 上打开“系统设置”，进入“Wi-Fi”，点击当前网络右侧的“详细信息”，在“TCP/IP”中查看 IP 地址。另一台电脑需要保存本代码文件夹并运行 `client.py`，然后将登录页面的服务端地址改为：

```text
http://服务端电脑的局域网IP:8765
```

例如服务端 IP 为 `192.168.1.105`，客户端填写 `http://192.168.1.105:8765`。两台电脑必须连接同一个局域网，macOS 弹出防火墙提示时应允许 Python 接收传入连接。
