# 红色文化学习打卡系统

本项目是计算机专业项目开发实践课程的 **可视化联网 C/S 版本**。系统使用 Python 编写，用户通过 Tkinter 桌面客户端操作，客户端使用 HTTP 和 JSON 与服务端通信，服务端负责业务处理并通过 SQLite 保存数据。

截至 2026 年 9 月 9 日，注册登录、公告与景点查询、学习打卡、积分统计、学习记录管理、管理员维护和权限检查等核心功能已经实现。全部程序和测试代码整理在 `李发鹏_项目代码_可视化联网CS` 文件夹中，课程报告、Postman 与 JMeter 实测、局域网双机验证、答辩 PPT 和 Git 截图文档仍需继续完成。

## 一 项目结构

```text
李发鹏_项目代码_可视化联网CS
          │
Tkinter 桌面客户端 client.py
          │
          │ HTTP 请求与 JSON 响应
          ▼
Python 服务端 server.py
          │
          │ 业务处理与权限检查
          ▼
LearningService service.py
          │
          │ SQL
          ▼
SQLite 数据库 database.py
```

虽然客户端和服务端使用 HTTP 通信，但用户通过单独的桌面客户端完成操作，因此本项目属于 C/S。浏览器访问服务端根地址时只显示运行状态，不能代替 `client.py` 的系统界面。

## 二 技术栈

| 部分 | 技术 | 作用 |
| --- | --- | --- |
| 桌面客户端 | Python、Tkinter、ttk | 登录注册、表格展示、查询和管理操作 |
| 网络通信 | HTTP、JSON、Bearer Token | 客户端与服务端交换数据 |
| 服务端 | Python `ThreadingHTTPServer` | 接收请求、返回状态码和 JSON 数据 |
| 业务层 | Python | 输入校验、权限检查、会话及业务处理 |
| 数据库 | SQLite | 保存普通用户、景点、用户景点打卡记录和公告 |
| 自动化测试 | unittest | 测试业务接口和桌面操作流程 |
| 接口与压力测试材料 | Postman、JMeter | 用于后续软件内实际测试和截图 |

本项目没有使用 Flask、FastAPI 或 Django。服务端采用 Python 标准库实现，代码规模较小，方便课程学习和讲解。

### 7.3 局域网演示

`server.py` 默认监听 `0.0.0.0`，直接在 PyCharm 中点击绿色三角形即可允许局域网连接。同机客户端继续使用 `http://127.0.0.1:8765`。

查询服务端 Mac 的局域网 IP 后，在另一台电脑的桌面客户端中填写：

```text
http://服务端电脑IP:8765
```

另一台电脑仍需运行 `client.py`，这也是 C/S 与直接使用浏览器访问的 B/S 的区别。客户端可以先点击“测试服务端连接”，成功后再登录。首次连接时如 macOS 弹出防火墙提示，需要允许 Python 接收传入连接。

## 十 项目说明

- 本项目是课程设计原型，主要用于验证红色文化学习打卡流程和 C/S 联网结构。
